# CCIC-Robotarm
基于海云捷讯的机械臂控制系统-2025年集成电路创新大赛（集创赛）FPGA应用赛道作品（机械臂控制部分）
本项目分为两个工程，视觉识别部分参见另一个仓库（视觉识别部分）
注意：ip核的版本可能和你的quartus不一致，将.qip文件中的版本号改成和你的quartus版本一致即可

基于 FPGA 的机械臂控制工程（2025 集成电路创新大赛 FPGA 应用赛道参赛项目，机械臂控制部分）。本仓库聚焦 **“坐标/仓库信息输入 → 逆解与动作编排 → 串口下发舵机/气泵指令”** 的完整链路。视觉识别侧在另一个仓库中维护。

---

## 1. 项目概述

本设计运行在 Intel Cyclone IV E（EP4CE6F17C8）平台，使用 Quartus Prime Lite 23.1 工程。顶层模块会在触发后完成一次自动搬运流程：

1. 根据目标点 `(x, y)` 计算机械臂姿态（高位/低位）。
2. 串口下发 5 路舵机位姿。
3. 控制气泵吸取/释放物块。
4. 根据仓库编号查询目标仓位坐标与方向。
5. 将物块放置到仓位后回到初始位。

顶层状态机实现了完整时序（等待、抬升、下降、吸放、回零）。

## 3. 顶层接口说明（`data_send_top`）

### 输入

- `sys_clk`：系统时钟（工程管脚绑定到 `PIN_E1`）。
- `sys_rst_n`：低有效复位（`PIN_E15`）。
- `key1`：启动按键输入（代码中取反后做按下检测）。
- `uart_rx`：仓库信息串口输入（`PIN_N14`）。
- `rx_camera`：视觉串口输入（`PIN_L13`，当前逻辑中仅透传到测试口）。

### 输出

- `tx_armcontrol`：机械臂舵机串口输出（`PIN_E7`）。
- `tx_pump`：气泵串口输出。
- `tx_done`：一次多舵机串口批量发送完成标志。
- `tx_test`：测试口（当前接 `rx_camera` 透传，`PIN_G1`）。
- `control_finish`：整套抓取放置流程完成标志。

## 4. 核心流程（状态机）

顶层 `state` 从 `d0` 到 `d24` 组织整个流程，关键阶段如下：

- **启动与参数锁存**：检测按键触发，锁存当前目标和偏移量。
- **物料区高位 → 低位**：先到高处，再下降抓取。
- **气泵吸取**：下发吸气指令并延时等待稳定。
- **查询仓位**：通过 `warehouse` 模块获取目标仓位坐标与方向。
- **仓位高位/低位放置**：到仓库高位、下降、放置、再抬升。
- **回初始位并结束**：回到默认姿态，置 `control_finish=1`。

> 说明：当前版本里视觉输入模块 `uart_camera` 实例被注释，`x_input/y_input` 在上电后有默认值（`132/80`），适合联调与离线动作验证。

## 5. 开发环境与构建

- Quartus Prime Lite: **23.1std.0**（工程创建版本）
- Device: **EP4CE6F17C8**
- Top-level entity: **`data_send_top`**

### 编译步骤

1. 打开 `quartus_prj/Robot_arm.qpf`。
2. 检查 IP 是否可用；若版本不一致，按本机 Quartus 版本重新生成或调整 `.qip` 关联。
3. 运行 `Analysis & Synthesis`、`Fitter`、`Assembler`。
4. 在 `quartus_prj/output_files/` 获取 `Robot_arm.sof` 并下载到 FPGA。

---

## 6. 串口与联调建议

- 机械臂舵机与气泵各自独立串口发送，请确认外设波特率与协议匹配。
- `all_instruction` 采用“单舵机逐条发送 + 延时”策略，便于避免总线拥塞。
- 若接入视觉仓库联动，建议先单独验证：
  1. `xyz_calculate` 输出范围；
  2. `warehouse` 返回坐标/方向的时序；
  3. 气泵指令在各状态的触发时机。

---

## 7. 已知注意事项

1. **IP 版本兼容性**：跨 Quartus 版本时，`.qip` / IP 可能需重新生成。
2. **工程输出目录较大**：`quartus_prj/db`、`output_files` 为编译产物。
3. **视觉模块默认未使能**：如需在线视觉坐标，请恢复 `uart_camera` 实例并检查协议。
